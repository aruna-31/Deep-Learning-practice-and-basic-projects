# Deep Learning Practice & Projects

A collection of deep-learning exercises, model implementations, experiments, and small applied projects used to build practical understanding of neural networks.

## Focus areas

- Neural network fundamentals
- Computer vision
- CNN-based models
- Transfer learning
- Model training and evaluation
- Experiment analysis
- Applied deep-learning projects

## Typical workflow

```
Dataset
   |
Preprocessing
   |
Neural network / pretrained model
   |
Training
   |
Validation
   |
Evaluation
```

## Tech stack

- Python
- TensorFlow / Keras
- PyTorch where applicable
- NumPy
- Pandas
- OpenCV
- Jupyter / Google Colab

## Repository purpose

This is a learning and experimentation repository rather than a single production application. Individual folders/notebooks contain implementation details for each experiment.
